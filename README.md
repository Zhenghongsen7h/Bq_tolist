# 便签 ToList

Windows 11 本地便签。双击桌面上的「便签 ToList」启动。

GitHub 公开仓库：[Zhenghongsen7h/Bq_tolist](https://github.com/Zhenghongsen7h/Bq_tolist)。

- **待办**每天独立记录。按回车添加，点击编号调整同级顺序。父项可添加子待办，父项和子项都可分别勾选完成，并通过「进度」按钮查看、编辑或删除多行进度。
- **截止日期**：在「待办进度」窗口的标题右侧设置，点击日期框内的日历图标选择日期，也可手动填写 `YYYY-MM-DD` 或点击旁边的「清除」。可只设置日期而不填写进度；点击保存后生效，取消不保存。删除进度保留已保存的截止日期；转移事项时截止日期保持不变。
- **转移未完成事项**：在待办页点击「移至次日」一键转移当前查看日期的未完成事项，或点击「移至指定日期…」选择其他日期。次日指当前查看日期的下一天；转移后自动打开目标日期，在已有清单末尾按原顺序追加并重新编号。子待办转移时带上父待办，保留内容、进度、优先级和完成状态。已完成子待办留在原日期；需要时保留原父项并在目标日期带上父项，确保两天的父子层级完整。
- 主待办和子待办默认不标记优先级。在「编辑」中选择紧急（红）、中等（黄）或普通（绿）并保存，圆点会出现在复选框右侧；选择「不标记」可清除。
- **日报**可直接编辑，也可从对应日期的待办页复制待办、子待办、各自的进度和完成状态。已设置优先级的任务同时复制「紧急程度：紧急／中等／普通」，未设置则不显示该项。复制按父子层级追加到已有正文，同一份清单内容只复制一次。
- **周报**从日报页选择同周的任意一篇或多篇。导入内容按日期排列，每段都能编辑，周报正文可另写总结。已导入的日期在该周内只复制一次。
- **随心记**是一页独立草稿。日报、周报和随心记会自动保存，也可以按 Ctrl+S。

## 运行和数据

从项目目录运行 `powershell -ExecutionPolicy Bypass -File .\create-shortcut.ps1` 可重新创建桌面快捷方式。若 Conda 环境移动了，给脚本传入 `-Pythonw` 和新的 `pythonw.exe` 路径。

应用使用 Python 3.12、Tkinter 和 SQLite。关闭应用后可备份 `%LOCALAPPDATA%\TodoListMemo\notes.sqlite3`，还原时将备份放回同一位置。更换项目目录后需要重新创建快捷方式。

## 版本与对话更新记录

### v0.2.3 · 待办截止日期（2026-11-18）

- 主待办和子待办有截止日期时，鼠标在「进度」按钮上停留约 0.35 秒显示紧凑矩形气泡「截止日期：YYYY-MM-DD」。气泡采用小一号字体、左右 8 像素／上下 4 像素留白；未设置日期不显示，移开、点击、滚动或切换页面时隐藏。修改前本地快照：`codex/backup-before-deadline-tooltip`。
- 截止日期日历每次打开显示今天所在月份，并将今天的日期格默认标为蓝色；打开或取消日历不修改原截止日期，点击日期后才更新。修改前本地快照：`codex/backup-before-calendar-today`。
- 根据用户确认的参考图纠正布局：撤掉底部日期栏，将截止日期移到标题右侧，标签在日期框上方，框内右侧为日历图标，旁边为「清除」，恢复正文输入区高度。修改前快照（包含未提交改动）：`codex/backup-before-deadline-layout-fix`。
- 主待办和子待办均支持选择日历、手动填写及清除；无效日期会提示修正，允许只保存日期。
- 日期与进度一起保存，取消不改动已有记录；删除进度保留已保存日期。仅设置截止日期时，「进度」按钮也显示蓝色，方便再次查看。
- 旧数据库自动补齐截止日期字段，已有事项默认不设置；转移未完成事项（包括拆分保留父项）时保留截止日期。
- 11 项 GUI／数据回归测试通过，覆盖今日高亮、日历选择、无效日期、保存与重新打开、取消、清除、持久化、父子事项转移，以及悬停气泡显示和清理。
- 修改前本地备份：`codex/backup-before-v0-2-3-deadline`。

### v0.2 · 基础界面更新（`816ef48`）

- 深色侧边导航、浅色工作区和待办统计卡片，统一四个页面的标题、间距与编辑区域。
- 待办输入与日报复制操作分区；双击待办文字也可以编辑。
- 切换页面、日期或勾选待办时，保留本次运行中尚未提交的待办输入（关闭程序后不保留）。
- 编辑、删除、勾选后保留列表滚动位置；长文字按可用宽度换行。
- 编辑器支持 Ctrl+A 全选，并显示聚焦边框；页面切换后仍显示自动保存提示。
- 默认窗口大小适应屏幕，最小尺寸为 780 × 560。
